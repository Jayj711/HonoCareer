## 语音边界

后端只负责文本 Agent（文本对话与流式输出）。ASR（语音识别）与 TTS（语音合成）在端侧闭环处理，后端不接收也不返回音频流。

## 数据库

- **异步 SQLAlchemy**（`mysql+asyncmy` 驱动），这是硬约束，不可改回同步。
- 模型统一 `Mapped` / `mapped_column` 声明，`db/__init__.py` 暴露 `engine` 与 `AsyncSessionFactory`。
- 共 15 张表：`users`、`refresh_tokens`、`profiles`、`resumes`、`defense_materials`、`sessions`、`session_materials`、`messages`、`responses`、`response_events`、`reports`、`weak_points`、`memory_settings`、`memories`、`audios`。
- **改结构一律走 Alembic**：`python -m alembic upgrade head`。`models.py` 里的 `create_tables()` 只建缺失表、不改已有表。
- 当前迁移链已 squash 为单个 `4a0e33d74a5c_init_tables`：`upgrade` 复用 `metadata.create_all` 建全部表，全新空库直接 `alembic upgrade head` 即可建表（已验证）。后续阶段改结构用 `alembic revision --autogenerate` 叠加增量迁移。

## 开发规范

**分层**：`api`（路由，薄）→ `services`（业务）→ `schemas`（DTO/VO）。路由只做参数绑定 + `Result.success(...)` 包裹，业务逻辑与 `BizError` 抛错都在 service 层。

**统一响应**：所有非 SSE 接口返回 `{ code, message, data, requestId }`，`code=0` 成功；业务错误 HTTP 状态码恒 200，用 body 里的 `code` 区分。FastAPI 默认的 422 参数校验错误已统一拦截，转成 `40001`（HTTP 200），`message` 带上出错字段路径（如 `参数错误: body.account`）。

| code | 含义 |
|---|---|
| 0 | 成功 |
| 40001 | 参数错误 |
| 40101 | 未登录 / token 缺失 |
| 40102 | token 过期或无效 |
| 40301 | 无权限 |
| 40401 | 资源不存在 |
| 40901 | 冲突（账号已存在 / 画像版本冲突） |
| 50001 | 服务器内部错误 |

**鉴权**：请求头 `Authorization: Bearer {accessToken}`；access token 用 JWT（HS256，`sub`/`iat`/`exp`），refresh token 为不透明随机串、存库并轮换（刷新时吊销旧 token），登出吊销该用户全部 refresh token。

**分页**：列表统一游标分页 `PageResult = { items, nextCursor, hasMore }`，游标为上一页最后一条的 id。

**其它**：日志对 `api_key`/`secret`/`token`/`password`/`Authorization` 等敏感字段自动脱敏（见 `config.py`）。
